# Descript

Next-generation functional language designed for concurrency and signal-oriented programming.

## Web Coder Friendly

Descript's syntax is aspired by mainstream script languages in web programming like Typescript, making Descript low-cost to take up.

## Forefront Design

Descript employs various innovative design patterns.

- Enhanced type deducing system brings users a relaxing and flexible experience under an overall strict-typed design.
- Signal-oriented programming and CFRP (Concurrent Functional Responsive Programming) are naturally and seamlessly embeded, making everything reactive and productive.
